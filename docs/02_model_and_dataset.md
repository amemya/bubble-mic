# 02. モデル選定・実部屋データ収集・評価指標設計

## 1. ベースモデル選定と段階的移行戦略

「他人の声を消す（音源分離に近いタスク）」に必要なモデル表現力と、実装・学習パイプライン構築のしやすさ（工数）の両面を踏まえ、以下の2段階で進めます。

| ステップ | モデル名 | STFT設定 (公式準拠) | パラメータ数 | 役割と移行基準 |
| :---: | :--- | :--- | :---: | :--- |
| **Step 1**<br>(高速検証) | **GTCRN**<br>(Original → Large) | 16kHz / 32ms窓(512) / 16msホップ(256)<br>(遅延32ms) | 48K (Orig)<br>〜 350K (Large) | PyTorch単一スクリプトでデータ合成・損失関数・ゲート連携を最速で検証するためのモデル。48Kで他人声の分離が頭打ち（半実録テストセットで **SI-SDR改善幅 < 8dB** または **無言時他人声の相対減衰 < 25dB**）になった場合は、チャネル数を広げた `GTCRN-Large` または Step 2 の `DeepFilterNet3` へ移行する。 |
| **Step 2**<br>(48kHz本命) | **DeepFilterNet3** | 48kHz / 20ms窓(960) / 10msホップ(480)<br>+ 先読み2フレーム (遅延40ms) | **約 2.1M** | 48kHzフルバンドの高音質と高い分離容量を持つ本命モデル。Rust製データローダ（`libdf`）とHDF5データセット変換が必要なため、Step 1でデータ配合比率と損失関数が固まってから学習を回すことで手戻りを防ぐ。 |

## 2. 「誰の声か（声質）」と「どの距離か（空間）」の両方を学習させる設計

もし学習データが「自分の声＝近接（残響なし）」「他人の声＝遠方（残響あり）」のみで構成されていると、モデルが「距離（残響の有無）」だけで判定してしまい、友人がデスクのすぐ横に来て喋った場合に消せなくなります。これを防ぐため、仕様とデータ構成を以下のように定義します。

* **目標仕様**: **「自分の声質（および口元で発せられた自分の非言語音）だけを抽出し、たとえデスクの近くであっても他人の声は消す」**
* **データ配合による強制**:
  自分が発話しつつ他人の声も重なる同時発話サンプル（全学習データの45%）のうち、**3分の2（全体の30%）は「室内の離れた位置（1.5〜3.5m）からの残響付き他人声」**とし、**残りの3分の1（全体の15%）にはあえて「残響の少ない（マイクの近くで喋った状態の）他人の声」**を混ぜます。これにより、モデルが「残響の有無（距離）」だけで解くことを防ぎ、**自分固有の基本周波数（$F_0$）・フォルマント・声道特性（声質）**を必ず手がかりとして併用するように強制します。

## 3. 実部屋を活用したデータ収集・合成パイプライン

実際に使用する寮の部屋が手元にあるメリットを最大限に活かします。`pyroomacoustics` によるシミュレーションは補助（バリエーション水増し用）とし、**実際の部屋でのスピーカー再生録音および実測インパルス応答（RIR）**をメインに使用します。

> **マイクと口元距離の固定について**:
> モデルの学習データ（自分の声や実測RIR）はマイクの周波数特性と近接効果（口元からの距離）に強く依存します。データ収録時と実際のVC運用時で**同じマイク・同じ口元距離（例：5〜10cm）**を維持してください（マイクを買い替えた場合は、新しいマイクで再収録・再ファインチューニングを行います）。

### 3.1 収録するもの（本番マイク・固定位置で録音）

1. **【Target】自分の通常発話（20〜30分）**:
   * 普段のVCの話し方、相槌、早口、小声など。
2. **【Target】自分の非言語音声（3〜5分、各20〜30回＋ピッチ/時間伸縮Augmentation）**:
   * 咳払い、咳、伸び（「ん〜〜っ」）、あくび、笑い声、引き笑い、ため息、息継ぎ、鼻すすり。
3. **【Noise ①】実際の部屋でスピーカーから流して再録音した「同居人・友人の声」**:
   * 同居人のデスク、ベッド、部屋の入り口など3〜5箇所にスピーカーを置き、以下を再生して**自分のマイクで録音**します。
     * 日本語会話コーパス（JVS、Common Voice、雑談配信音声など）
     * **他人の非言語音声（VocalSound等から抽出した「他人の笑い声」「他人の咳払い」「他人のくしゃみ」）** ← ※遠方で他人が笑ったり咳をした時に完全消去するために必須。
   * あわせて、各位置から**対数スイープ信号（TSP / Sine Sweep、10秒程度）**を再生して録音し、逆フィルタで**実測RIR（部屋の実際のインパルス応答）**を10〜20パターン取得します。実測RIRがあれば、任意のコーパス音声に畳み込むだけで「本物の部屋の響き」を大量に合成できます。
4. **【Noise ②】自分のデスク周りの近接過渡ノイズ（5〜10分）**:
   * 自分が黙った状態で、**キーボードの激しい打鍵音、マウスの連打音、机を叩く音、コップを置く音、コントローラーの操作音、椅子のきしみ音**を録音し、消すべきNoiseとして明示的に混ぜます。

### 3.2 ミキシング比率（5パターン構成）

| パターン | 全サンプル中の割合 | 入力 $x(t)$ | 教師信号（Target $y(t)$） | 学習させる能力 |
| :--- | :---: | :--- | :--- | :--- |
| **A. 同時発話（遠方他人）** | **30%** | 自分の発話 + **実測RIR付き遠方他人声** + 打鍵/環境音 | **自分の発話** | 通常のVC中に同居人の会話と打鍵音を消す能力 |
| **B. 同時発話（近接他人）** | **15%** | 自分の発話 + **残響の少ない近接他人声** + 打鍵/環境音 | **自分の発話** | **距離だけでなく「自分の声質」で他人と見分ける能力** |
| **C. 自分の非言語音＋背景音** | **20%** | **自分の咳/伸び/笑い/ため息** + 他人声 + 打鍵/環境音 | **自分の咳/伸び/笑い/ため息** | **自分の非言語音声を絶対にノイズとして消さない能力** |
| **D. 自分無言＋他人声・打鍵音** | **25%** | **無音(自分)** + **他人の会話・笑い・咳 + 打鍵/クリック音** | **完全無音 ($\mathbf{0}$)** | **自分が黙っている時に同居人の声も打鍵音もミュートする能力** |
| **E. クリーン自己音声** | **10%** | 自分の発話/非言語音 + 微弱な環境音 | 自分の発話/非言語音 | 静かな時に自分の声を劣化させない能力 |

## 4. 損失関数（Loss Function）の設計

無言時の他人の声の漏れを抑える際、単純な対数エネルギー損失を使うと、無音区間を限りなくゼロ（$-\infty\text{ dB}$）に押し潰そうとして勾配が過大になり、自分の小声や話し始め（アタック）まで削ってしまう副作用が出ます。また、合計エネルギーではなくサンプル数 $N$ で割った**平均パワー（dBFS相当）**で閾値を定義する必要があります。

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{cMSE}} + \lambda_{\text{nv}} \mathcal{L}_{\text{nonverbal\_preserve}} + \lambda_{\text{mute}} \mathcal{L}_{\text{inactive\_mute}}$$

1. **非言語音の削りすぎ防止ペナルティ ($\mathcal{L}_{\text{nonverbal\_preserve}}$)**
   パターンC（自分の咳・伸び・ため息区間）において、推定スペクトル振幅 $|\hat{Y}|$ が正解 $|Y|$ を下回った（過剰抑制した）場合のみペナルティを課す非対称損失：
   $$\mathcal{L}_{\text{nonverbal\_preserve}} = \left\| \max\big(0,\; |Y|^{0.3} - |\hat{Y}|^{0.3}\big) \right\|_2^2$$
2. **フロア付き無言時リーク抑制損失 ($\mathcal{L}_{\text{inactive\_mute}}$)**
   パターンD（自分が無言で他人が喋っている、または打鍵音が鳴っている区間、サンプル数 $N$）において、出力の平均パワーが **`-65 dBFS`（聴感上の無音フロア $L_{\text{floor}} = -65\text{ dB}$）** 以下に落ちていればペナルティをゼロにし、それを超えて漏れている分だけを叩くヒンジ型対数パワー損失：
   $$\mathcal{L}_{\text{inactive\_mute}} = \max\left(0,\; 10 \log_{10}\left(\frac{1}{N}\|\hat{y}\|_2^2 + \epsilon\right) - (-65\text{ dB})\right)$$

## 5. 「半実録テストセット」の構築と定量評価指標

自分の声とスピーカーの他人声を**同時に**録音したファイルだけでは、正解のクリーン波形 $y_{\text{clean}}(t)$ が存在しないため、SI-SDR や非言語音エネルギー保持率を正確に計算できません。

そこで、評価用として**同じマイク・同じゲイン・同じ口元位置のまま、以下の3つを別々に録音し、デジタル上で加算合成した「半実録テストセット（Semi-real Test Set）」**（`data/eval_semi_real/`）を作成します。

1. $s_{\text{self\_speech}}(t)$: スピーカーを止めて録った自分の発話（60秒）
2. $s_{\text{self\_nv}}(t)$: スピーカーを止めて録った自分の咳・伸び・あくび・笑い声・ため息（60秒）
3. $n_{\text{room\_And\_desk}}(t)$: 自分は無言のまま、同居人位置のスピーカーから雑談配信（会話＋笑い声）を流し、同時に手元でキーボード打鍵・マウスクリックを行った録音（120秒）

これらを足し合わせた $x_{\text{test}}(t) = s_{\text{self}}(t) + n_{\text{room\_and\_desk}}(t)$ をモデルに入力し、出力 $\hat{y}(t)$ を正解 $s_{\text{self}}(t)$ と比較することで、本物の部屋の音響特性のまま全指標を厳密に算出できます。

| 指標名 | 測定対象の区間 | 定義・計算方法 | 合格目標値 |
| :--- | :--- | :--- | :---: |
| **1. 無言時相対リーク減衰量**<br>(`Relative Leakage Attenuation`) | $s_{\text{self}}(t) = 0$（自分無言＋同居人会話＆打鍵音のみ）の区間 | 自分の通常発話の平均RMSレベル（dBFS）に対する、無言区間出力RMSレベルの相対差（マイクゲイン設定に依存しない指標） | **自分の平均発話レベル比 `< -40 dB`**<br>(かつ絶対値 `< -60 dBFS`) |
| **2. 非言語音エネルギー保持率**<br>(`Non-verbal Retention`) | $s_{\text{self\_nv}}(t)$（自分の咳・伸び・笑い・ため息）の区間 | $10 \log_{10}\left(\frac{\sum |\hat{y}_{\text{nv}}(t)|^2}{\sum |s_{\text{self\_nv}}(t)|^2}\right)$（クリーン正解波形に対する出力エネルギー比） | **`-1.5 dB 〜 0 dB` 以内**<br>(エネルギー保持率 `70% 〜 100%`) |
| **3. 同時発話 SI-SDR**<br>(`Overlap SI-SDR`) | $s_{\text{self\_speech}}(t) + n_{\text{room\_and\_desk}}(t)$ の重複区間 | 正解クリーン発話 $s_{\text{self\_speech}}(t)$ に対する出力 $\hat{y}(t)$ の SI-SDR (dB) | **入力比 `+10 dB` 以上**<br>(ベースライン比 `+6 dB` 以上) |
| **4. エンドツーエンド遅延**<br>(`E2E Latency ms`) | 実機ループバック測定 | スピーカーからクリック音を鳴らし、物理マイク → BubbleMic → 仮想マイク出力までの時間差 | **`< 75 ms`** |
