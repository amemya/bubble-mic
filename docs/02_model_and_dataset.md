# 02. モデル選定・実部屋データ収集・評価指標設計

## 1. ベースモデル選定と段階的移行戦略

「他人の声を消す（音源分離に近いタスク）」に必要なモデル表現力と、公開されている事前学習済み重み（Pretrained Weights）の有無・実装工数を踏まえ、以下の2段階で進めます。

| ステップ | モデル名 | STFT設定 (公式準拠) | パラメータ数 | 役割と移行基準 |
| :---: | :--- | :--- | :---: | :--- |
| **Step 1**<br>(オフライン検証専用) | **GTCRN (Original)** | 16kHz / 32ms窓(512) / 16msホップ(256)<br>(遅延32ms) | **約 48K**<br>(公式学習済み重みあり) | PyTorch単一スクリプトでデータ合成・損失関数・ゲート連携を最速で検証するためのモデル。**リアルタイム運用には使用しません**（`01_architecture.md §1`）。※GTCRNのチャネル数を拡大した独自Large版には公開学習済み重みがなくゼロからの事前学習が必要になるため、48Kで容量不足（半実録テストセットで **SI-SDR改善幅 < 8dB** 等）が見られた場合は、直接 Step 2 の **DeepFilterNet3** へ移行する。 |
| **Step 2**<br>(48kHz・本命／リアルタイム運用) | **DeepFilterNet3** | 48kHz / 20ms窓(960) / 10msホップ(480)<br>+ 先読み2フレーム (遅延40ms) | **約 2.1M**<br>(公式学習済み重みあり) | 48kHzフルバンドの高音質と高い分離容量を持つ本命モデル。Step 1でデータ配合比率と損失関数が固まってから HDF5 データセットを生成して Fine-tuning を回すことで手戻りを防ぐ。Fine-tuning 時は §1.1 の注意点を適用する。 |

### 1.1 DeepFilterNet3 を Fine-tuning する際の注意点

1. **帯域別移動平均正規化による「絶対音量差・近接効果」の消失への対策**
   * DeepFilterNet3（`libdf`）は入力特徴量を、ERBバンドごとの対数パワーから時定数 `norm_tau = 1.0 s` の指数移動平均 $\mu_b(t)$ を引いて正規化します（`band_mean_norm`）。また DF 帯域（約 `4.8 kHz` 以下）の複素スペクトルは振幅の移動平均で割って単位ノルム化します（`band_unit_norm`）。
   * 自分が1秒以上黙り同居人だけが喋っていると、これらの正規化状態が同居人の音量とスペクトル傾斜に追従し、**本プロジェクトの主要な手がかりである「口元と遠方の絶対音量差」と「近接効果による低域強調」が特徴量から打ち消されます**（残響や声質の手がかりは残るため、影響の大きさは実測で確認する）。GTCRN はこの移動平均正規化を行わないため、Step 1 では消えていた同居人の声が Step 2 で漏れ始める、という形で現れます。
   * **対策（基本）: 正規化状態への下限クランプ**
     $\mu_b(t)$ と `band_unit_norm` の正規化状態の両方に、自己発話基準 $L_{\text{self}}(b)$ から `12〜15 dB` を引いた下限 $\mu_{\min}(b)$ を設けます。
     $$\mu_b(t) \leftarrow \max\big(\mu_b(t),\; \mu_{\min}(b)\big)$$
     自分が喋っている間の正規化は公式実装と同じ挙動になるため、公開学習済み重みをそのまま活かせ、モデル構造の変更も不要です。$\mu_{\min}(b)$ は $L_{\text{self}}$ のキャリブレーションと同時に測定します。
     * 副作用として、自分の小さなため息なども「小さい＝遠い」と見えやすくなるため、静穏時の非言語音保持率（§4 指標2）で確認します。
   * **代替案（基本対策で不十分な場合）**: 正規化前の相対バンドパワー $(E_{\text{erb}}(t, b) - L_{\text{self}}) / 40$ をゼロ初期化した線形層経由でエンコーダ特徴に加算する（Zero-init Adapter）、またはキャリブレーションで得た固定平均で正規化する（固定統計量正規化）。
   * **検証方法**: §4 指標7（無言経過時間ごとのリーク曲線）を Step 1 と Step 2 で比較し、Step 2 で無言 `1秒` 以降にリークが増えていないことを確認します。
2. **教師が無音のサンプルでの損失のゼロ除算**
   公式学習パイプラインの `SiSdrLoss` は分母に正解波形のエネルギーを持つため、教師が完全無音となるパターンD（および §3 の無音ポーズフレーム）でゼロ除算（`NaN`）を起こします。**教師が無音のサンプルでは `SiSdrLoss` をマスク**し、`LocalSnrLoss` を使う場合も下限（`-15 dB`）へのクランプを入れます。使用する損失の有効・無効は公式設定ファイルで確認します。
3. **高域処理（ERBゲイン）も学習対象に含める**
   DeepFilterNet3 は約 `4.8 kHz` 以上の高域を実数値のERBゲイン（`erb_dec`）だけで処理し、DF複素フィルタは低中域のみに作用します。高域の子音や他人の笑い声の息成分も消すため、Fine-tuning ではDF側だけでなく **`erb_dec` も更新対象に含めます**（一部の層を凍結する場合に注意）。
4. **$p_{\text{interferer}}$ ヘッドの追加**
   ボトルネック（GRU出力）から線形層1枚＋Sigmoidの補助ヘッドを追加します（`01_architecture.md §3.1`）。ONNX エクスポート時は出力に $p_{\text{interferer}}$ を含めます。

## 2. 放置録音を活用した「本物の実環境データ」収集パイプライン

合成データだけで学習させようとすると、「スピーカー再生特有の音色（スマホ等の低域不足）」をモデルが学習してしまい、本物の人間の声が消えにくくなるリスクがあります。
しかし、**実際の寮の2人部屋で生活している環境では、自分が黙っている時にマイクを録音しっぱなしにしておく（放置録音する）だけで、スピーカーを介さない「100%本物の同居人・友人の会話や笑い声」が自然に集まります**。これを消去対象（Noiseデータ）の主軸に据えます。

> **マイクと口元距離の固定について**:
> 学習データはマイクの周波数特性と近接効果（口元からの距離）に依存します。データ収録時と実際のVC運用時で**同じマイク・同じ口元距離**を維持してください（マイクを買い替えた場合は、新しいマイクで再収録・再ファインチューニングを行います）。

### 2.1 収録するもの（すべて自分の本番マイク・固定位置で録音）

1. **【Target ①】自分の通常発話（20〜30分）**:
   * 同居人がいない静かな時間帯に、普段のVCの話し方、相槌、早口、小声などを録音します。
2. **【Target ②】自分の非言語音声（5〜10分、各30〜50回）**:
   * 咳払い、咳、伸び（「ん〜〜っ」）、あくび、笑い声、引き笑い、ため息、息継ぎ、鼻すすり。有声（「ん〜〜」「あ゛〜」）と無声（「はぁ〜」「コホッ」、息笑い）の両方を含めます。
   * **水増し（Augmentation）**: 時間伸縮（`0.85〜1.15` 倍）、微小なゲイン変動、EQ変動を中心とし、**ピッチシフトは `±1〜1.5 半音` 以内**に留めます。大きなピッチシフトは声道フォルマントだけでなく、近接効果による低域強調の帯域まで周波数シフトさせてしまい、自分の声道特性と近接音響の手がかりがぼやけるためです。
3. **【Noise ①（最重要）】放置録音による「本物の同居人・来客の会話と笑い声」（30分〜数時間）**:
   * 同居人が部屋で友人と喋っている時や通話している時に、自分のマイクで放置録音します（自分は離席し、近接の呼吸音などが混入しないようにします）。
   * これにより、**本物の人間の声道特性 × 本物の部屋の残響 × 自分のマイクのオフアクシス特性 × 実際の音量バランス**が完全に反映された最強の妨害話者データが手に入ります。
   * *自分の突発音（咳など）の除外方法*: 一般的な音声VADでは同居人の声と区別できないため、「口元の音は同居人の声より `15〜25 dB` 大きい」という物理差を利用し、**単純な振幅レベル閾値（同居人会話ピークの `+6 dB` 以上）を超えた区間とその前後1秒を機械的に除外**します。
   * *ミキシング時の音量維持*: 放置録音には実際の部屋でのリアルな音量（dBFS）がそのまま記録されているため、学習データ合成時には過度な正規化を行わず、**録音された実レベルの `±6 dB` 以内の微調整にとどめて加算**します。
4. **【Noise ②】自分のデスク周りの近接過渡ノイズ（5〜10分）**:
   * 自分が黙った状態で、**キーボードの激しい打鍵音、マウスの連打音、机を叩く音、コップを置く音、コントローラーの操作音、椅子のきしみ音**を録音します。
5. **【Noise ③（未知の来客への汎化用）】実測RIRを畳み込んだ多様な遠方話者コーパス**:
   * 特定の同居人だけでなく未知の友人が部屋に来た時にも消せるよう、同居人位置に置いたスピーカー（低域まで出るもの）で測定した**実測RIR（インパルス応答）**をJVS、Common Voice、VocalSound（他人の笑い声・咳）に畳み込み、ランダムなEQ変動を加えて遠方妨害話者の水増しデータとして使用します。
   * *なぜ「残響のないドライな他人声」を混ぜないのか*: デスク真横での会話は手動ミュート運用（スコープ外）としたため、消去対象を「部屋の残響を伴う遠方の他人声」に統一します。もし残響のないドライな他人声を大量にNoise側に入れてしまうと、モデルが「近くで鳴っていても自分の通常発話の声紋と違う音は消す」と学習してしまい、従来のTSEと同じく**声紋が崩れる自分の咳・あくび・ため息まで削りやすくなる副作用**が生じるためです（ドライな他人声の混入率 `0% vs 5%` は Phase 4 の比較実験項目としてのみ検証します）。
6. **【共通】ルームトーン（1〜2分）**:
   * 誰も喋らず打鍵もしていない状態の部屋の定常音（マイクの自己雑音・空調・PCファン）を録音します。§2.3 のノイズフロア整合に使います。

### 2.2 ミキシング比率（5パターン構成）

| パターン | 全サンプル中の割合 | 入力 $x(t)$ | 教師信号（Target $y(t)$） | 学習させる能力 |
| :--- | :---: | :--- | :--- | :--- |
| **A. 同時発話（放置録音の同居人）** | **30%** | 自分の発話 + **放置録音の本物の同居人・友人会話（実レベル±6dB）** + 打鍵音 | **自分の発話** | 実際の音量・残響バランスで同居人・友人の会話と打鍵音を消す能力 |
| **B. 同時発話（実測RIR付き未知話者）** | **15%** | 自分の発話 + **実測RIRを畳み込んだ多様な話者（会話・笑い声・ランダムEQ）** + 打鍵音 | **自分の発話** | **特定の同居人だけでなく、初めて部屋に来た友人の声も消す汎化能力** |
| **C. 自分の非言語音＋背景音（低SIR〜静穏）** | **20%** | **自分の咳/伸び/笑い/ため息** + 打鍵/環境音（半数は **$\mathrm{SIR} \in [-5\text{dB}, +20\text{dB}]$** の同居人会話を重畳） | **自分の咳/伸び/笑い/ため息** | **静穏時は非言語音を確実に残し、同居人の大声と重複した時は同居人の声を漏らさない能力** |
| **D. 自分無言＋同居人会話・打鍵音** | **25%** | **無音(自分)** + **同居人の会話・笑い・咳 + 打鍵/クリック音** | **完全無音 ($\mathbf{0}$)** | **自分が黙っている時に同居人の声も打鍵音もミュートする能力** |
| **E. クリーン自己音声** | **10%** | 自分の発話/非言語音 + 微弱な環境音 | 自分の発話/非言語音 | 静かな時に自分の声を劣化させない能力 |

> **フェイルセーフ（遮断優先）に基づくパターンCと非対称損失の切り替え**:
> パターンCから「同居人の声の方が大きいサンプル（低SIR：`-5 dB 〜 +5 dB`）」を除外してしまうと、本番で自分の伸びと同居人の大声がぶつかったときのモデルの挙動が未定義になり、かえって声が漏れる原因になります。
> そこで、**パターンCの入力には低SIR（`-5 dB〜`）のサンプルも含めた上で、非言語音の削りすぎを罰する非対称損失 $\mathcal{L}_{\text{nonverbal\_preserve}}$ は「$\mathrm{SIR} \ge +5\text{ dB}$（自分の音の方が明確に大きいサンプル）」にだけ適用**します。これにより、低SIRのサンプルでは通常の再構成損失 $\mathcal{L}_{\text{cMSE}}$（教師信号には同居人の声が含まれないため同居人の声を消す方向に働く）のみが適用され、「ぶつかって分離が苦しい時は伸びが削れてよいので同居人の声を消す」という基本方針（優先度1）をモデルが直接学習できます。

### 2.3 合成時の前処理とノイズフロア整合

個別に収録した Target・Noise ①・Noise ② には、それぞれマイクの自己雑音や空調・PCファン音などの**定常ノイズフロア（例：`-65 〜 -60 dBFS`）**が含まれています。これらをそのまま加算すると、パターンAでは入力のフロアが約 `+4.8 dB`（3本分）、パターンDでは `+3 dB`（2本分）になる一方、教師信号のフロアは1本分またはデジタルゼロになり、**モデルが「定常ノイズの量」を手がかりに開閉を学習するショートカット**が生じます。本番では常にマイク1本分のフロアしか入らないため、以下の処理で学習時と分布を揃えます。

1. **打鍵音（Noise ②）のイベント切り出し**: 連続録音をそのまま加算せず、打鍵・クリックの過渡イベント区間だけを切り出し（前後の定常区間はゼロにして）重畳します。
2. **教師信号の無音隙間のフロア整理**: Target ①・② の発話と発話の間にある定常ノイズだけを、緩やかなエキスパンダーで落とします。ため息や息継ぎを削らないよう、前後のホールドマージンを十分に取り、処理は控えめにします。
3. **共通ルームトーンの1回加算**: すべてのパターン（A〜E）の混合入力 $x(t)$ に、§2.1 で録ったルームトーンを**実レベルで1回だけ**加算し、さらに `-70 dBFS` 程度の微弱なランダムノイズを加えて、録音本数に由来するフロア差の手がかりを隠します。教師信号にはルームトーンを加えません。
4. **前段HPFの適用**: すべての学習・評価データの入力と教師に、推論時と同じ `60 Hz` の2次 Butterworth HPF を適用します（`01_architecture.md §1`）。

### 2.4 フレーム単位ラベルの出力

動的ミキサーは、合成時に以下のフレーム単位ラベル（STFTホップ単位）を学習サンプルと一緒に出力します。

| ラベル | 定義 | 用途 |
| :--- | :--- | :--- |
| **他者音声ラベル** $z_{\text{int}}(t) \in \{0, 1\}$ | そのフレームの他者音声（Noise ①・③）の成分レベルが **$L_{\text{self}} - 35\text{ dB}$ 以上**なら `1`（合成前の妨害音単体から計算） | $p_{\text{interferer}}$ ヘッドの BCE 損失（§3） |
| **教師無音フレームラベル** $z_{\text{sil}}(t) \in \{0, 1\}$ | 教師信号のフレームレベルが `-70 dBFS` 未満で、かつ前後 `50〜100 ms` 以内に自己発声がないフレームなら `1` | 無言時リーク損失をパターンD以外の無音ポーズにも適用（§3） |
| **サンプルSIR** | パターンCの自分の非言語音と妨害音の比（サンプル単位） | $\mathcal{L}_{\text{nonverbal\_preserve}}$ の適用フラグ（§3） |

* 他者音声ラベルの閾値（$L_{\text{self}} - 35\text{ dB}$）を低くしすぎると、ごく小さな背景の声まで陽性になり、ゲートがほとんど開かなくなります。逆に高すぎると、伸びの最中の小さな同居人の声を検出できません。初期値は、漏れが同時マスキングで聞こえなくなる目安（自分の音より `-15 dB`）を検出できる水準として設定し、Phase 4 で調整します。

## 3. 損失関数（Loss Function）の設計

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{cMSE}} + \lambda_{\text{nv}} \cdot \mathbb{I}(\mathrm{SIR} \ge 5\text{ dB}) \cdot \mathcal{L}_{\text{nonverbal\_preserve}} + \lambda_{\text{mute}} \mathcal{L}_{\text{inactive\_mute}} + \lambda_{\text{int}} \mathcal{L}_{\text{BCE}}$$

各項はいずれも**要素数（フレーム数・ビン数）で平均**した値とします。Step 1（16kHz / 257 bins / 16ms hop）から Step 2（48kHz / 481 bins / 10ms hop）へ移行した際に、ビン数やフレーム数の違いで各 $\lambda$ の実質的な重みが変わるのを防ぐためです。

1. **高SIR限定・非言語音の削りすぎ防止ペナルティ ($\mathcal{L}_{\text{nonverbal\_preserve}}$)**
   パターンCのうち、**自分の非言語音が妨害音より `+5 dB` 以上大きいサンプル（または背景が静かなサンプル、フラグ $\mathbb{I}(\mathrm{SIR} \ge 5\text{ dB}) = 1$）**においてのみ、推定スペクトル振幅 $|\hat{Y}|$ が正解 $|Y|$ を下回った（過剰抑制した）場合にペナルティを課します：
   $$\mathcal{L}_{\text{nonverbal\_preserve}} = \frac{1}{TF}\sum_{t,f} \max\big(0,\; |Y(t,f)|^{0.3} - |\hat{Y}(t,f)|^{0.3}\big)^2$$
2. **短時間フレーム単位・フロア付き無言時リーク抑制損失 ($\mathcal{L}_{\text{inactive\_mute}}$)**
   * クリップ全体の平均パワーで判定すると、3秒のうち `50 ms` だけ `-48 dBFS` で漏れても、クリップ平均は $-48 + 10\log_{10}(0.05/3.0) \approx -65.8\text{ dBFS}$ となって閾値 `-65 dB` を下回り、勾配がゼロになります。そのため、**`20〜50 ms` の短時間フレーム $m$（フレーム長 $L$）ごとに**パワーを計算してヒンジ損失をとります。
   * 適用対象は、**パターンDの全フレームに加え、パターンA・B・Cの中の教師無音フレーム（$z_{\text{sil}} = 1$）**です。GRU等の再帰構造を持つモデルでは、最初から無言の区間よりも「自分が喋り終えた直後 `0.2〜0.8秒` の息継ぎ・文間ポーズ」（隠れ状態が通過モードのまま残っている瞬間）で最も他人の声が漏れやすいため、ここを直接抑制します。
   $$\mathcal{L}_{\text{inactive\_mute}} = \frac{1}{|\mathcal{M}|}\sum_{m \in \mathcal{M}} \max\!\left(0,\; 10\log_{10}\!\left(\frac{1}{L}\|\hat{y}_m\|_2^2 + \epsilon\right) - (-65\text{ dB})\right)$$
   （$\mathcal{M}$：対象フレームの集合。`-65 dBFS` 以下に落ちていればペナルティはゼロとし、無音を無理に押し潰して勾配が暴走し、小声や話し始めまで削る副作用を防ぎます。）
3. **他者音声検知ヘッドの損失 ($\mathcal{L}_{\text{BCE}}$)**
   $p_{\text{interferer}}(t)$ と他者音声ラベル $z_{\text{int}}(t)$（§2.4）の Binary Cross-Entropy をフレーム平均でとります。
   $$\mathcal{L}_{\text{BCE}} = -\frac{1}{T}\sum_{t}\Big[z_{\text{int}}(t)\log p_{\text{interferer}}(t) + \big(1 - z_{\text{int}}(t)\big)\log\big(1 - p_{\text{interferer}}(t)\big)\Big]$$

## 4. 「半実録テストセット」の構築と定量評価指標

自分の声と同居人の声を**同時に**録音したファイルだけでは、正解のクリーン波形 $y_{\text{clean}}(t)$ が存在しないため、SI-SDR や非言語音エネルギー保持率を正確に計算できません。

そこで、評価専用として**学習データとは完全に別の録音セッション（別の会話内容・別の時間帯）**で、同じマイク・同じゲイン・同じ口元位置のまま以下の3つを別々に録音し、デジタル上で加算合成した**「半実録テストセット（Semi-real Test Set）」**（`data/eval_semi_real/`）を作成します。

1. $s_{\text{self\_speech}}(t)$: 静かな時に録った自分の通常発話（`3〜5分`）
2. $s_{\text{self\_nv}}(t)$: 静かな時に録った自分の咳・伸び・あくび・笑い声・ため息（有声・無声の両方を含む、`3〜5分`）
3. $n_{\text{room\_and\_desk}}(t)$: 自分は無言のまま、**同居人が実際に友人と談笑・大笑いしている時の放置録音（または学習用とは別動画・別話者のスピーカー再生録音）**に、手元のキーボード打鍵・マウスクリック音を合わせた録音（`5〜10分`）

これらを足し合わせた $x_{\text{test}}(t) = s_{\text{self}}(t) + n_{\text{room\_and\_desk}}(t)$ をパイプラインに入力して評価します。テストケースには、**同居人の会話の合間にあくびが始まり途中で同居人が喋り出すケース**と、**自分が喋った直後に同居人が喋り出すケース**を含めます。

### 4.1 Shadow Filtering による自己音と漏れの分離

単純に「出力 − 正解」で漏れを測ると、優先度1の方針で意図して削った自分の伸びが「漏れ」として計上されてしまいます（出力が 0 でも $-s_{\text{self}}$ が残差になる）。そこで **Shadow Filtering** を用います。

1. $x_{\text{test}}(t)$ をパイプラインに通し、各フレームで推論された **Main DNN / Sidechain NR のマスク・DFフィルタ係数とゲート係数 $\alpha(t)$ をすべて記録**します。
2. マスク・係数を固定すると、パイプライン全体は入力に対する線形時変フィルタ $\mathcal{H}_{\theta}[\cdot]$ になります。これを自己音と妨害音に個別に適用します。
   $$\tilde{s}_{\text{out}}(t) = \mathcal{H}_{\theta}\big[s_{\text{self}}(t)\big], \qquad \tilde{n}_{\text{leak}}(t) = \mathcal{H}_{\theta}\big[n_{\text{room\_and\_desk}}(t)\big]$$
   （線形性により $y_{\text{final}}(t) = \tilde{s}_{\text{out}}(t) + \tilde{n}_{\text{leak}}(t)$ が成り立ちます。）
3. 漏れ量は $\tilde{n}_{\text{leak}}$ のレベル、自己音の保持量は $\tilde{s}_{\text{out}}$ と $s_{\text{self}}$ の比で、それぞれ独立に評価します。

> **実装要件**: GTCRN・DeepFilterNet3 の推論コードから、フレームごとのマスク（GTCRN：複素マスク、DFN3：ERBゲイン＋DF係数）を取り出せるようにしておきます。評価スクリプト（`src/eval/`）は Phase 2 の最初からこの方式で実装します（エキスパンダー等のベースラインも、ゲインを固定すれば同様に適用できます）。

### 4.2 評価指標

| 指標名 | 測定対象の区間 | 定義・計算方法 | 合格目標値 |
| :--- | :--- | :--- | :---: |
| **1. 無言時相対リーク減衰量**<br>(`Relative Leakage Attenuation`) | $s_{\text{self}}(t) = 0$（自分無言＋同居人会話・大笑い＆打鍵音のみ）の区間 | 自分の通常発話の平均RMSレベル（dBFS）に対する、無言区間出力RMSレベルの相対差（マイクゲイン設定に依存しない指標） | **自分の平均発話レベル比 `< -40 dB`**<br>(かつ絶対値 `< -60 dBFS`) |
| **2. 静穏時の非言語音エネルギー保持率**<br>(`Quiet Non-verbal Retention`) | $s_{\text{self\_nv}}(t)$（背景に同居人の会話がない／静穏時の自分の咳・伸び・笑い・ため息） | $10 \log_{10}\left(\frac{\sum |\tilde{s}_{\text{out}}(t)|^2}{\sum |s_{\text{self\_nv}}(t)|^2}\right)$（Shadow Filtering による自己音の出力エネルギー比。有声・無声を分けても集計） | **`-1.5 dB 〜 0 dB` 以内**<br>(エネルギー保持率 `70% 〜 100%`) |
| **3. 非言語音重複時の他人声リーク**<br>(`Overlap Non-verbal Leakage`) | 自分の伸び・あくび $s_{\text{self\_nv}}(t)$ と同居人の会話が重なった区間（途中割り込みケースを含む） | Shadow Filtering による漏れ成分 $\tilde{n}_{\text{leak}}(t)$ のRMSレベル。あわせて同区間の自己音保持率 $\|\tilde{s}_{\text{out}}\| / \|s_{\text{self\_nv}}\|$ も記録する（削れは許容するため目標値は設けない） | **自分の通常発話比 `< -35 dB`**<br>(または自分の音に対して `< -15 dB`) |
| **4. 同時発話 SI-SDR**<br>(`Overlap SI-SDR`) | $s_{\text{self\_speech}}(t) + n_{\text{room\_and\_desk}}(t)$ の重複区間 | 正解クリーン発話 $s_{\text{self\_speech}}(t)$ に対する出力 $\hat{y}(t)$ の SI-SDR (dB) | **入力比 `+10 dB` 以上**<br>(ベースライン比 `+6 dB` 以上) |
| **5. 発話直後ポーズのリーク**<br>(`Post-speech Pause Leakage`) | 自分の発話終了後 `0.2〜0.8 秒` の区間（背景に同居人の会話あり） | 同区間の $\tilde{n}_{\text{leak}}(t)$ のRMSレベル（自分の通常発話比） | **`< -40 dB`**（指標1と同水準） |
| **6. 他者音声検知の性能**<br>(`Interferer Detection`) | ①伸び・あくびに同居人の声を重ねた区間、②静穏時の自分の非言語音区間 | ①同居人の声が自分の音より `-15 dB` の条件での $p_{\text{interferer}} \ge \tau_{\text{int}}$ の検出率、②静穏時の誤検知率 | ①**検出率 `> 90%`**<br>②**誤検知率 `< 5%`** |
| **7. 無言経過時間ごとのリーク曲線**<br>(`Leakage vs. Silence Duration`) | 自分が黙ってから `0〜5 秒` の区間（同居人が会話を継続） | 無言開始からの経過時間ごとの $\tilde{n}_{\text{leak}}$ のレベル | Step 2 で無言 `1秒` 以降にリークが増加しないこと（§1.1 の確認） |
| **8. エンドツーエンド遅延**<br>(`E2E Latency ms`) | 実機ループバック測定 | スピーカーからクリック音を鳴らし、物理マイク → BubbleMic → 仮想マイク出力までの時間差 | **`< 75 ms`** |

## 5. 【拡張仮案（優先度3）】重複時の非言語音分離を時間-周波数マスクで重点学習させる場合

基本設計（優先度1：サンプル全体の $\mathrm{SIR} \ge +5\text{ dB}$ のみで $\mathcal{L}_{\text{nonverbal\_preserve}}$ を有効化）および拡張仮案A（優先度2：`01_architecture.md §3.5` の帯域別ゲート $\alpha(t, b)$）を試した後に、さらに**「同居人が大声で笑っている最中に自分が伸びをした（$\mathrm{SIR} < +5\text{ dB}$）ケースでも、Main DNN 単体で自分の伸びの帯域をより多く残したい」**となった場合に検討する発展的な学習案です。

* **サンプル単位フラグから「時間-周波数ビン単位の局所SIRマスク $W_{\text{dom}}(t, f)$」への細分化**:
  サンプル全体の $\mathrm{SIR}$ が $+5\text{ dB}$ 未満であっても、合成前の正解スペクトルから計算した**局所優位マスク $W_{\text{dom}}(t, f) = \mathbb{I}\big(|S_{\text{nv}}(t, f)| > \sqrt{2}\,|N_{\text{int}}(t, f)|\big)$（自分の非言語音が妨害音より `+3 dB` 以上勝っている時間-周波数ビンのみ `1`、それ以外は `0`）**を損失に掛けることで、同居人の声が乗る中域ビンは消しつつ自分の伸びが勝っている低域・高域ビンだけに削りすぎ防止ペナルティを適用します。
  $$\mathcal{L}_{\text{nonverbal\_preserve}}^{\text{(masked)}} = \frac{1}{TF}\sum_{t,f} W_{\text{dom}}(t,f)\,\max\big(0,\; |Y(t,f)|^{0.3} - |\hat{Y}(t,f)|^{0.3}\big)^2$$
