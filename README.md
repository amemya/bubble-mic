# BubbleMic (`~/bubble-mic`)

> **「口元の音響バブル（自分の発話＋咳・伸び・笑いなどの非言語音声）だけを抽出し、打鍵音およびバブル外の同居人・来客の会話を遮断するリアルタイムVCフィルタ」**

## 1. 背景と解決したい課題

2人部屋の寮などの共有空間でボイスチャット（Discord等）をする際、同居人やその友人の話し声が自分のマイクに乗ってしまう問題があります。

| 既存アプローチ | 挙動 | 寮の2人部屋VCにおける課題 |
| :--- | :--- | :--- |
| **汎用AIノイキャン**<br>(Discord Krisp / RNNoise) | 「人間の声」全般を残し、打鍵音や環境音のみを消す | 同居人や友人の話し声・笑い声も「人間の声」としてそのままクリアに通してしまう。 |
| **従来の目標話者抽出 (TSE)**<br>(VoiceFilter / SpEx+ 等) | 事前登録した「自分の声紋ベクトル」と一致する音だけを残す | 母音・通常発話に基づく声紋ベクトルと一致しない**非言語音声（咳払い、伸び、あくび、笑い声、息遣い）がすべてノイズとして消去**され、VCでのリアクションが不自然になる。 |

---

## 2. BubbleMic のコア設計（4つの柱）

本プロジェクトでは、以下の4つの設計柱によって**「打鍵音と同居人の声は消えるのに、自分の咳や伸び・笑い声は自然に通る」**システムを構築します。

1. **並列サイドチェイン構成（Main Path: 自分専用統合DNN ＋ Sidechain Path: 汎用NR連動の削りすぎ救済ゲート）**
   * **Main Path（本線）** では、ファインチューニング済みの単一DNNがマイク入力から「打鍵音・環境ノイズ」と「同居人の声」を一括で消去し、自分の声と非言語音 $Y_{\text{dnn}}$ を抽出します。直列に2つのモデルを繋がないため、遅延の加算や前段ノイキャンによる息成分の消失が起きません。
   * **Sidechain Path（並列補助経路）** では、素の汎用ノイキャンを通した信号 $Y_{\text{nr}}$（打鍵音のみ除去された人間の声）を監視し、**「口元で大きな生体音が鳴っているのに、Main DNNがそれを大きく削り落としてしまった瞬間」**だけ $Y_{\text{nr}}$ を極短時間ブレンドして非言語音を救済します。打鍵音は $Y_{\text{nr}}$ の時点で消えているため、ゲーム中の連打でゲートが誤作動することはありません。
2. **公式学習済みモデル準拠の遅延設定（アルゴリズム遅延 32〜40ms / 実測 50〜75ms）**
   * DiscordのPing（約50ms）と合わせても片道100〜125ms（会話で違和感のない150ms以下）に収まるため、STFT設定を変更せず **GTCRN（16kHz、32ms）** や **DeepFilterNet3（48kHz、先読み2フレーム込み40ms）** の学習済み重みをそのまま初期値として活用します。
3. **「距離（実部屋録音・実測RIR）」＋「声質（近接他人声の混入）」のハイブリッド学習**
   * 実際の寮の部屋（同居人のデスク・ベッド位置）にスピーカーを置いて再録音した遠方会話データに加え、友人がデスク横に来たケースに備えて「残響の少ない近接の他人声」も消去対象（Noise側）に一定割合混ぜることで、距離と声質の両方を手がかりとして学習させます。
4. **ハードウェア（単一指向性ダイナミックマイク＋口元5cm配置）との相乗効果**
   * ソフトウェア処理に加え、マイク選びと角度・距離配置によって物理的な音量差（SIR）を `20〜25 dB` 以上稼ぐことで、入力段階から高い分離有利性を確保します。

```text
~/bubble-mic/
├── README.md
├── docs/
│   ├── 01_architecture.md          # システム・並列サイドチェイン信号処理設計
│   ├── 02_model_and_dataset.md     # モデル選定・実部屋データ収集・評価指標設計
│   └── 03_realtime_audio_routing.md# マイク選定ガイド・Discord接続・検証ロードマップ
├── data/
│   ├── raw_self_speech/            # 自分の通常発話録音（20〜30分）
│   ├── raw_self_nonverbal/         # 自分の咳・伸び・笑い声・ため息録音
│   ├── raw_desk_transients/        # 自分のキーボード打鍵音・マウスクリック・机衝撃音
│   ├── raw_room_rirs/              # 実部屋で測定したインパルス応答・スピーカー再録音
│   ├── raw_interferers/            # 妨害話者用コーパス（JVS / CommonVoice / 非言語音等）
│   └── eval_semi_real/             # 個別録音（自分/打鍵/スピーカー他人声）と加算テストセット
├── src/
│   ├── dataset/                    # 実測RIR畳み込み＆5パターン動的ミキシング
│   ├── models/                     # GTCRN / DeepFilterNet3 ファインチューニング定義
│   ├── dsp/                        # 過剰抑制検知サイドチェインゲート
│   ├── eval/                       # SI-SDR / 相対リーク減衰 / 非言語保持率 評価スクリプト
│   └── engine/                     # ONNX Runtime / libdf リアルタイム推論エンジン
└── checkpoints/                    # 学習済みモデル
```
